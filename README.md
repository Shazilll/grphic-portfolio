# Shazil Pervaiz – Portfolio

Keep all files and folders together exactly as they are.

## Put it live on GitHub Pages
1. Create a new repository on GitHub (for example `portfolio`).
2. Upload everything inside this folder (index.html, css, js, images, videos). Index.html must be at the top level of the repository.
3. Go to Settings > Pages. Under "Build and deployment", choose "Deploy from a branch", select the `main` branch and the `/ (root)` folder, then Save.
4. After a minute your site is live at https://YOUR-USERNAME.github.io/portfolio/

## Change things
- Text and layout: index.html
- Colours and fonts: css/style.css
- Replace an image or video by keeping the same file name.
